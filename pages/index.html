标注细节：超 Int 范围整数上浮 Int64（repr 保真，JS number 会丢精度而这里不会）；1e10 降级规范化为 1.0e10（N 层 1≡1.0 值等价）；Option 写法 = MoonBit 后缀糖 String?。
  
demo 引擎 = MoonBit src 包 js 后端出口（wasm-gc 的 String ABI 依赖 js-string-builtins 提案，当前工具链未支持——已实测登记）。
  
本页由 CI 自动构建部署（push master → .github/workflows/pages.yml：js 构建 + 22 断言 smoke 门 + GitHub Pages 发布，smoke 红不上线）；本地重建引擎产物（ffi.js 不入库）：MOON_CC=clang moon build --target js pages/ffi && cp _build/js/debug/build/pages/ffi/ffi.js pages/（release 会 tree-shake link.exports，用 debug——已登记待解）；冒烟：node pages/smoke.mjs。
